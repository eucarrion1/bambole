# Remix Bambole

Criar uma plataforma completa de E-commerce/Loja Virtual moderna, inteligente, responsiva, altamente profissional e escalável, contendo todos os recursos avançados utilizados atualmente pelas maiores plataformas de vendas online do mercado.

O sistema deve possuir:

Site da loja virtual

Painel administrativo

Área do cliente

Sistema financeiro

Sistema fiscal

CRM de clientes

Sistema de marketing

Automação de vendas

Relatórios avançados

Integrações futuras

O objetivo é criar uma plataforma premium semelhante a:

Shopify

Nuvemshop

Tray

Mercado Livre

Amazon

Shopee

WooCommerce
